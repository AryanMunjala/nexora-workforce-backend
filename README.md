# Nexora Workforce — Backend

Java 21 and Spring Boot REST API for the Nexora Workforce employee management system, backed by MySQL.

- API: https://nexora-backend-production-3f15.up.railway.app
- Frontend: https://nexora-frontend-production-ebc0.up.railway.app
- Source monorepo: https://github.com/AryanMunjala/nexora-workforce

## Run locally

```bash
mvn spring-boot:run
```

Set database connection variables using `.env.example`. Do not commit real credentials.
